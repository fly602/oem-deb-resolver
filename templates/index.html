OEM 补丁包下载配置

配置补丁仓库和补丁包列表，工具自动解析同目录相关包和依赖，并下载所需 deb 包。

当前基础镜像包列表共有 {{ base_count }} 个包。支持本地路径或 HTTP URL。

自动从 base 列表文件名检测，也可手动选择

支持直接粘贴 apt sources.list 中的仓库行。优先级按行顺序（越靠前优先级越高）。

示例：

deb [trusted=yes] https://aptly.uniontech.com/pkg/snipe-2500u1/release-candidate/... unstable main deb [trusted=yes] https://aptly.uniontech.com/pkg/commercial-snipe-2500u1/release-candidate/... unstable commercial

示例：dde-shell、custom-oem-fix=1.2.3-1

全量升级：扫描补丁仓库所有包，下载 base 中存在且版本更高的包（不指定具体包名）
预览和全量升级预览会自动保存当前配置。

解析流程说明

  1. 查找补丁包 — 从补丁仓库查询，取版本最高的包。未找到则提示（显示 base 中的版本）。
  2. 查找相关包 — 在补丁包同一目录下扫描其他包，若 base 中存在且版本更低则一并下载。
  3. 解析依赖 — 下载后使用 dpkg-deb --info 解析 Depends 字段。对比 base 版本，满足则跳过，不满足则从补丁仓库下载。
  4. 递归处理 — 新下载的包也按步骤 1-3 处理其依赖，直到无新包。
  • 直接通过 HTTP 获取远程仓库元数据，不依赖本地 apt-get
  • 依赖解析使用 dpkg-deb（下载后的 .deb 文件），结果最准确
